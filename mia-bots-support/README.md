# Mia Bots Support: a Mia Bot plugin

Ask Mia Bots support a how-to question or report a problem from the chat, and check for a reply on a ticket by its number.

## What you get

- **MCP server** `mia-bots-support` at `https://support.miabots.com/mcp` (Streamable HTTP).
- **Skill** `support`: when and how to ask a Mia Bots how-to question or report a problem to Mia Bots support, ask before sending, and check for a reply.

### Tools

| Tool | What it does |
|---|---|
| `contact_support` | Send a Mia Bots how-to question, a problem report, or a follow-up on a ticket, to Mia Bots support. Returns a ticket number. |
| `check_support_reply` | Check one ticket, by its number, for a reply from Mia Bots support. |
